# Quiz — Elementy Fizyki Współczesnej (EFW)

Interaktywna baza **300 pytań** przygotowująca do kolokwium testowego z Elementów Fizyki Współczesnej (25 minut, UPEL).

- **Tryb Nauki**: nauka całej bazy lub wybranego działu (w tym pytania z poprzednich kolokwiów) ze szczegółowymi wyjaśnieniami po sprawdzeniu.
- **Tryb Kolokwium**: 25 losowych pytań ze wszystkich 6 działów w limicie 25 minut, z podsumowaniem działów i przeglądem wyjaśnień.
- **Powtórka błędów**: ponowne rozwiązywanie wyłącznie błędnych pytań.
